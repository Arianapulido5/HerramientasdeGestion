# Paleta de Colores - VirtualID

## Colores Principales

### Azul Primario
- Nombre: VirtualID Blue
- HEX: #1a56a0
- RGB: 26, 86, 160
- Uso: botones principales, encabezados, elementos destacados

### Azul Oscuro
- Nombre: VirtualID Dark
- HEX: #154a8a
- RGB: 21, 74, 138
- Uso: hover de botones, bordes activos

### Azul Claro
- Nombre: VirtualID Light
- HEX: #f0f8ff
- RGB: 240, 248, 255
- Uso: fondos de secciones, tarjetas, contenedores

## Colores Secundarios

### Blanco
- HEX: #ffffff
- Uso: fondo principal, texto sobre fondos oscuros

### Gris Texto
- HEX: #1a1a1a
- Uso: texto principal del cuerpo

### Gris Medio
- HEX: #555555
- Uso: texto secundario, subtitulos, placeholders

### Gris Claro
- HEX: #cccccc
- Uso: bordes, lineas divisoras, inputs deshabilitados

## Colores de Estado

### Exito
- HEX: #28a745
- Uso: mensajes de autenticacion exitosa, confirmaciones

### Error
- HEX: #dc3545
- Uso: mensajes de error, rostro no reconocido

### Advertencia
- HEX: #ffc107
- Uso: alertas, procesos en espera

## Tipografia
- Fuente principal: Arial, sans-serif
- Fuente codigo: Courier New, monospace
- Tamano base: 16px
- Escala: 12px / 14px / 16px / 18px / 24px / 32px
